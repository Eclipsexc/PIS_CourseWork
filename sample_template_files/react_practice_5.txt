Q1. Для чого у React використовують state?
A1. State зберігає локальні дані компонента, зміна яких запускає повторний render і оновлення інтерфейсу.

Q2. Чим props відрізняються від state?
A2. Props передаються компоненту ззовні і є вхідними даними, а state належить компоненту або hook-логіці всередині нього.

Q3. Для чого потрібен useEffect?
A3. useEffect використовується для side effects після render, наприклад завантаження даних, підписки або синхронізації з зовнішнім API.

Q4. Що таке controlled input?
A4. Controlled input отримує value з React state і змінюється через onChange, тому джерелом істини є стан компонента.

Q5. Навіщо потрібен key під час рендеру списків?
A5. Key допомагає React стабільно зіставляти елементи списку між render і коректно оновлювати тільки змінені частини.
