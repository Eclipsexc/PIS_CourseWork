# Sample Question Templates

Це папка для готових файлів шаблонів, які можна імпортувати через UI.

Підтримуваний формат:

```text
Q1. Текст питання
A1. Еталонна відповідь
```

Можна використовувати `.txt` або `.pdf`. Для PDF бекенд передає файл в `ai_ml_service`, де текст витягується і парситься у Q/A блоки.
