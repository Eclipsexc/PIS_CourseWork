Q1. Що таке транзакція в базі даних?
A1. Транзакція є групою операцій, які виконуються атомарно: або всі зміни застосовуються, або всі відкатуються.

Q2. Що таке рівень ізоляції транзакцій?
A2. Рівень ізоляції визначає, які проміжні зміни інших транзакцій видно поточній транзакції і які аномалії можуть виникати.

Q3. Для чого потрібен cache?
A3. Cache зменшує затримку і навантаження на основне сховище, але потребує правильної інвалідації та контролю актуальності даних.

Q4. Що таке idempotency?
A4. Idempotency означає, що повторне виконання операції дає той самий кінцевий результат, що важливо для retry і мережевих збоїв.

Q5. Для чого потрібен rate limiting?
A5. Rate limiting обмежує кількість запитів від клієнта або сервісу, щоб захистити систему від перевантаження і зловживань.

Q6. Що таке message queue?
A6. Message queue зберігає повідомлення між producer і consumer, дозволяючи обробляти задачі асинхронно та розв'язувати сервіси.

Q7. Чим authentication відрізняється від authorization?
A7. Authentication підтверджує особу користувача, а authorization визначає, які дії або ресурси йому дозволені.

Q8. Що таке JWT?
A8. JWT є підписаним token, який містить claims і дозволяє серверу перевіряти автентичність без зберігання сесії на бекенді.

Q9. Для чого потрібна міграція бази даних?
A9. Міграція версіонує зміни схеми бази даних і дозволяє контрольовано застосовувати їх у різних середовищах.

Q10. Що таке N+1 query problem?
A10. N+1 виникає, коли один запит отримує список сутностей, а потім для кожної сутності виконується окремий додатковий запит.

Q11. Для чого потрібен load balancer?
A11. Load balancer розподіляє трафік між інстансами сервісу і може виконувати health checks для недоступних вузлів.

Q12. Що таке circuit breaker?
A12. Circuit breaker тимчасово зупиняє виклики до нестабільної залежності, щоб система не витрачала ресурси на повторні збої.

Q13. Що таке observability?
A13. Observability дає розуміння стану системи через logs, metrics і traces, щоб швидше знаходити причини проблем.

Q14. Чим horizontal scaling відрізняється від vertical scaling?
A14. Horizontal scaling додає більше інстансів, а vertical scaling збільшує ресурси одного сервера.

Q15. Що таке pagination?
A15. Pagination ділить великий список результатів на сторінки або cursor-блоки, щоб не передавати весь набір даних одразу.

Q16. Для чого потрібні indexes у PostgreSQL?
A16. Indexes прискорюють пошук, JOIN, сортування і фільтрацію, але збільшують обсяг даних і ціну операцій запису.

Q17. Що таке deadlock?
A17. Deadlock виникає, коли транзакції взаємно чекають ресурси одна одної і жодна не може продовжити виконання.

Q18. Для чого потрібен background worker?
A18. Background worker виконує довгі або відкладені задачі поза HTTP-request, щоб не блокувати відповідь користувачу.

Q19. Що таке API contract?
A19. API contract описує очікувані endpoints, payload, status codes і правила сумісності між клієнтом та сервером.

Q20. Як планувати graceful degradation?
A20. Graceful degradation означає, що система зберігає критичні функції доступними навіть коли частина залежностей недоступна.
